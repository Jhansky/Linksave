Descargador de audio

Convierte tu enlace a MP3

Pega un enlace de audio directo o un enlace de una plataforma compatible. Para convertir enlaces de plataformas a MP3, configura una API de descarga que tengas permiso de utilizar.

Cómo funciona: si pegas un enlace directo a un archivo de audio, LinkSave intenta abrirlo para descargarlo. Para extraer audio de YouTube u otras plataformas, el servidor/API debe realizar la conversión; GitHub Pages solo aloja el HTML y no convierte archivos por sí mismo.

Configuración de API compatible (opcional)

Usa una API compatible con solicitudes POST JSON y con CORS habilitado para tu dominio de GitHub Pages. No uses una instancia pública sin permiso ni pongas claves privadas en este HTML: el código será visible para todos.
